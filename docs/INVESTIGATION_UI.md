# Code-Archon Investigation Studio

The Investigation Studio is a local browser UI for starting and monitoring a Code-Archon repository investigation. It launches the existing `archon.cli investigate` command as a subprocess; it does not implement a separate investigation pipeline.

## Start

After the normal project setup:

```powershell
pip install -e ".[dev]"
Copy-Item .env.example .env
# Add your GROQ_API_KEY to .env
docker-compose up -d
python -m pytest tests/ -q
archon-ui
```

The UI opens at **http://127.0.0.1:8765**. If the `archon-ui` command is not recognized in an existing environment, rerun `pip install -e ".[dev]"` to refresh the editable installation.

Alternatively, run `python -m archon.webui`. Use `python -m archon.webui --no-browser` to suppress automatic browser launch, or `--port 8766` to select another local port.

## Run an investigation

1. Enter the absolute path to the source repository on the machine running the UI.
2. Describe the investigation goal.
3. Choose an output folder separate from the source repository (for example, `./demo-output`).
4. Set the maximum iteration count and choose LLM-assisted or heuristic mode.
5. Start the investigation. The monitor displays real CLI output and phase updates.
6. When the process completes, use the result links to open the generated dashboard or report.

Only one investigation can run at a time because the existing graph-store setup clears/rebuilds graph state per run. The launcher defaults to binding to `127.0.0.1`; do not expose it to an untrusted network because it can launch processes against folders accessible to your account.

The output dashboard is still generated by the existing CLI's documentation/export path. The launcher does not change AST parsing, retrieval, graph building, agent behavior, evidence verification, or finding promotion.
